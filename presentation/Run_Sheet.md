## Anticipated Questions

| Anticipated Questions | Owner | Answer |
| --------------------- | ----- | ------ |
| What led you guys to choose this project? | Connor | We were looking for something technically meaningful and with a technology that we didn't have a lot of experience before. We have not had much experience with computer vision tasks, so this project stuck out. Also, it gives us the opportunity to learn - even a little - bit of ASL, which none of us have significant experience in. |
| ML/DL models aren't necessarily built to work together, how do you plan to seamlessly integrate multiple models into the prediction process, without negatively impacting size requirements or speed? | Isaac | This will be some trial and error, but we'll start with a UI differentiation between the different models (e.g. one page for one model, another page for another model), and depending on the UI component, sent a request to a particular endpoint. This will have it so our app, at least initially, doesn't have to do any preprocessing to know which model to send the input to. |
| What's the Plan B if you can't find/train a model with a high-enough accuracy? | Braden | Find another model, we'll have to settle on the model with the best performance given the time constraints. Every project has a risk, this one is one of ours.  |
| What's the intended scope of the project? | Connor | We want to start with fingerspelling, and eventually go up to a small set (~250) of signs, each taken care of by a different model (since we've found models for fingerspelling, and models for signs, but not for both). We'll start with sign recognition as opposed to translation, and eventually move to fuller sentence translation if there's remaining time, and it seems feasible. |
